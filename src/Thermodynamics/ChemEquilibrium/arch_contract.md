# KiThe: математический и архитектурный контракт фазовой устойчивости

## 1. Назначение

Подсистема фазовой устойчивости должна отвечать на вопрос:

> может ли отсутствующая фаза появиться в бесконечно малом количестве и уменьшить термодинамический потенциал текущего равновесного состояния?

Она не должна определять конечное количество новой фазы. Это задача следующего fixed-Active-Set расчета.

Подсистема должна работать для любой многокомпонентной фазы, поддерживаемой термодинамической моделью KiThe. Чистая однокомпонентная фаза является частным случаем общего алгоритма и не должна иметь отдельной фундаментальной формулировки.

---

## 2. Опорное состояние

Пусть при заданных `P,T` уже найдено и принято локальное равновесие для текущего Active Set.

Для активных веществ известны:

* количества `n_i > 0`;
* химические потенциалы `μ_i`;
* матрица элементного состава `A_active`;
* полный элементный инвентарь системы.

Химический потенциал активного вещества вычисляется из той же термодинамической модели, которая использовалась при решении основной системы:

`μ_i = g_i°(T) + RT ln a_i`.

Никакая отдельная упрощенная модель химических потенциалов для stability analysis не допускается.

---

## 3. Элементные потенциалы

Для активного равновесного ансамбля существуют элементные потенциалы `λ_j`, удовлетворяющие

`μ_i = Σ_j a_ij λ_j`

для активных компонентов.

В матричной форме:

`A_active λ = μ_active`.

Основная nonlinear formulation KiThe остается reaction-basis formulation. Элементные потенциалы не становятся неизвестными основной задачи и не заменяют существующую архитектуру.

Они реконструируются после принятия локального решения исключительно как двойственные термодинамические величины, необходимые для анализа фазовой устойчивости.

Реконструкция должна контролировать:

* численный ранг;
* норму остатка `A_active λ - μ_active`;
* конечность всех величин.

Если `A_active` имеет неполный элементный ранг, `λ` может быть неединственным. Это само по себе не является ошибкой.

Однако значение `λ · c` является физически однозначным только для такого элементного вектора `c`, который принадлежит пространству

`Range(A_active^T)`.

Поэтому нельзя использовать произвольное minimum-norm решение `λ` для проверки фазового направления, которое активный ансамбль не способен обеспечить.

---

## 4. Пробная фаза

Рассмотрим неактивную фазу `β`, содержащую `q` потенциальных компонентов.

Ее пробный внутренний состав задается мольными долями

`x = (x_1, ..., x_q)`,

где

`x_i ≥ 0`

и

`Σ_i x_i = 1`.

Для каждого состава `x` фазовая модель определяет активности

`a_i^β(x,T,P)`

и химические потенциалы

`μ_i^β(x,T,P) = g_i°(T) + RT ln a_i^β(x,T,P)`.

Таким образом, stability analysis должен использовать обычную `PhaseActivityModel`, а не отдельную упрощенную модель только для фазового теста.

---

## 5. Элементный состав пробной фазы

Пусть строка `a_i` матрицы элементного состава относится к компоненту `i` пробной фазы.

Молярный элементный состав пробной фазы равен

`c_β(x) = Σ_i x_i a_i`.

Чтобы бесконечно малое количество такой фазы могло появиться с сохранением элементов, активный фазовый ансамбль должен быть способен отдать тот же элементный вектор.

Поэтому допустимый пробный состав обязан удовлетворять условию

`c_β(x) ∈ Range(A_active^T)`.

При полном элементном ранге активной системы это условие выполняется автоматически.

При неполном ранге оно является существенным ограничением задачи.

Эквивалентно, если `N` задает базис ортогонального дополнения к `Range(A_active^T)`, то

`N^T c_β(x) = 0`.

Это ограничение нельзя заменять эвристикой или игнорировать.

---

## 6. Tangent-plane distance для реагирующей системы

Для допустимого состава пробной фазы определяется молярная функция

`TPD_β(x) = Σ_i x_i [ μ_i^β(x,T,P) - a_i · λ ]`.

Эквивалентно,

`TPD_β(x) = ḡ_β(x,T,P) - λ · c_β(x)`,

где `ḡ_β` — молярная энергия Гиббса пробной фазы.

Физический смысл:

* `ḡ_β` — энергия Гиббса одного моля пробной фазы;
* `λ · c_β` — химическая стоимость того же набора элементов в существующем равновесном ансамбле.

Искомая величина:

`TPD_β,min = min TPD_β(x)`

по всем допустимым составам `x`.

Схема:

```text
inactive phase β
       │
       ▼
допустимый состав x
       │
       ▼
μ_i^β(x,T,P)
       │
       ▼
TPD_β(x)
       │
       ▼
min по x
       │
 ┌─────┼─────┐
 ▼     ▼     ▼
< 0    = 0   > 0
 │      │     │
 ▼      ▼     ▼
неуст. граница устойч.
```

---

## 7. Критерий

Теоретическая классификация:

`TPD_min < 0`

означает, что существует состав новой фазы, появление которого уменьшает `G`. Текущий Active Set не является глобально устойчивым.

`TPD_min = 0`

соответствует фазовой границе.

`TPD_min > 0`

означает, что бесконечно малое появление рассматриваемой фазы термодинамически невыгодно.

Практические конечные пороги `dg_create` и `dg_keep` относятся к политике гистерезиса и не являются частью определения TPD.

---

## 8. Состав зарождающейся фазы

Stability analysis обязан возвращать не только

`TPD_min`,

но и точку минимума

`x* = argmin TPD_β(x)`.

Это физически наиболее выгодный состав зарождающейся фазы.

Он является естественным источником состава phase seed после активации:

```text
TPD minimization
      │
      ├── TPD_min  → решение об активации
      │
      └── x*       → состав phase seed
```

Политика `PhaseTotalSeedPolicy` определяет общий масштаб начального количества новой фазы.

Но распределение этого количества между компонентами должно определяться `x*`, а не равномерным или произвольным распределением.

Если

`n_seed`

— общий seed новой фазы, то в идеальном случае

`n_i,seed = n_seed x_i*`.

Поскольку log-mole formulation требует строгой положительности активных компонентов, нулевые координаты `x_i*` могут получать малый численный composition floor с последующей перенормировкой.

Этот floor является исключительно численной деталью seed и не изменяет результат stability analysis.

---

## 9. Чистая фаза как частный случай

Если фаза содержит один компонент, то

`x_1 = 1`.

Минимизировать нечего, и общая формула автоматически дает

`TPD = μ_β - a_β · λ`.

Для чистой конденсированной идеальной фазы

`a_β = 1`

по термодинамической активности, поэтому

`μ_β = g_β°(T)`.

Следовательно,

`TPD = g_β°(T) - a_β · λ`.

Отдельная математическая ветка `PureCondensedSpecies` для этого не требуется.

---

## 10. Текущие ideal-модели

Для `IdealSolution`

`a_i = x_i`,

поэтому

`TPD(x) = Σ_i x_i [g_i°(T) + RT ln x_i - a_i·λ]`.

Для `IdealGas`

`a_i = x_i P/P°`,

поэтому

`TPD(x) = Σ_i x_i [g_i°(T) + RT ln x_i + RT ln(P/P°) - a_i·λ]`.

В случае полного элементного ранга эти функции являются выпуклыми по `x` для идеальной смеси, и задача имеет хорошо определенный глобальный минимум.

Реализация вправе использовать аналитические или специализированные решения для идеальных моделей, если они математически эквивалентны общей TPD-минимизации.

Однако архитектурный контракт должен оставаться сформулирован через общую TPD-задачу, чтобы последующее добавление non-ideal activity models не потребовало изменения смысла phase stability.

---

## 11. Неполный элементный ранг

Неполный ранг `A_active` нельзя считать автоматически ошибкой.

В этом случае необходимо:

1. определить пространство `Range(A_active^T)`;
2. ограничить допустимые trial compositions условием элементной реализуемости;
3. минимизировать TPD только в этом допустимом множестве.

Нельзя:

* выбирать произвольное `λ`;
* вычислять `a_candidate · λ`;
* интерпретировать результат как физическую driving force,

если элементный вектор кандидата лежит вне пространства, обеспечиваемого активным ансамблем.

Это особенно важно для Active Set, в котором некоторые элементные ограничения стали линейно зависимыми.

---

## 12. P,H = const

Для принятого решения задачи `P,H=const` известна найденная равновесная температура `T*`.

Фазовая устойчивость проверяется при

`P = const`

и

`T = T*`

по той же TPD-постановке, что и для обычной задачи `P,T`.

Причина состоит в том, что принятое P,H-состояние должно одновременно:

* удовлетворять энтальпийному ограничению;
* быть химически и фазово устойчивым при собственной найденной температуре.

Если stability analysis активирует новую фазу, следующий монолитный P,H solve снова определяет одновременно новый состав и новую температуру при прежнем `H_target`.

Нельзя выполнять stability test при первоначальном temperature seed.

---

## 13. Локальный и глобальный минимум

Для общего non-ideal phase model TPD может быть невыпуклой и иметь несколько stationary points.

Поэтому production-ready stability analysis не может считать единственный локальный минимум доказательством устойчивости.

Архитектура должна позволять:

* несколько начальных точек;
* deterministic multistart;
* специальные analytical starts;
* последующее применение global/semi-global strategy при появлении соответствующих моделей.

Для текущих идеальных моделей следует использовать их математическую структуру и не вводить ненужную стохастическую сложность.

---

## 14. Результат stability analysis

Результат для одной фазы должен концептуально содержать:

```rust
phase
active
minimum_tpd
incipient_composition
element_potential_evidence
```

`minimum_tpd` имеет единицы J/mol.

`incipient_composition` задается в локальном порядке компонентов данной фазы и нормирована на единицу.

Для исключенной фазы stability calculation вообще не требуется.

Для unsupported thermodynamic model следует возвращать явную ошибку capability, а не фиктивную driving force.

---

## 15. Разделение обязанностей

Подсистема фазовой устойчивости:

```text
accepted candidate
       │
       ▼
element potentials
       │
       ▼
TPD problem for each
inactive candidate phase
       │
       ▼
TPD_min + x*
```

Она НЕ должна:

* сама менять `PhaseSet`;
* сама активировать фазу;
* сама выбирать величину phase seed;
* сама запускать новый nonlinear solve.

Внешний дискретный цикл использует ее результат:

```text
TPD report
   │
   ▼
hysteresis policy
   │
   ▼
activation decision
   │
   ▼
PhaseSet change
   │
   ▼
phase seed from x*
   │
   ▼
new fixed-set solve
```

---

## 16. Главный архитектурный принцип

В KiThe должна существовать одна термодинамически корректная концепция фазовой устойчивости:

> minimization of tangent-plane distance over the admissible composition domain of the candidate phase.

Чистые фазы, многокомпонентные идеальные растворы и будущие неидеальные фазовые модели должны быть частными случаями этого контракта, а не отдельными несвязанными алгоритмами.
