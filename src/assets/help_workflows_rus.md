## Типовые рабочие процессы

### Один эксперимент

#### Импорт и первичная проверка

1. Откройте **File Manager > Import Data** для сырого TXT/CSV с заголовками колонок. Если нужно сразу задать метаданные опыта, используйте **New Experiment**. Выберите файл и привяжите время (`t`), массу или сигнал прибора (`m`) и температуру (`T`), если она измерялась. Проверьте единицы до импорта.
2. Для изотермического опыта без измеренной температурной колонки укажите известную температуру в метаданных. Колонка `T` не обязательна. Если прибор записал почти постоянную температуру, привяжите эту колонку; позднее можно вычислить её среднее значение.
3. Нажмите **Import experiment** / **Select**. Создаются графики `m vs t` и, если температура привязана, `T vs t`. Сначала проверьте их, затем изменяйте данные.

#### Очистка и подготовка

1. Удалите участки запуска и остановки прибора, не относящиеся к опыту. Выделите лишний интервал и нажмите **Cut selected** либо задайте границу через **Cut before time**. Эти команды удаляют строки; пропущенные измерения они не восстанавливают.
2. Используйте **Move time to zero**, если начало опыта должно соответствовать `t = 0`. После каждого изменения строк или времени проверяйте график.
3. Если прибор записал напряжение, выберите сигнал и примените **From mV to mg**. Сначала настройте калибровочную прямую. Результат создаёт колонку массы; исходное напряжение можно сохранить для сравнения.
4. Рассчитывайте относительную массу/конверсию по той колонке массы, которую собираетесь анализировать. В **Input value** задайте ненулевое время baseline: средняя масса до этого времени используется как начальная. Значение `0` отклоняется, поскольку оно выбрало бы только первую точку. Relative mass и conversion безразмерны и имеют противоположные направления отсчёта.
5. Применяйте фильтры и сглаживание к нужной исходной колонке. Savitzky-Golay (SG) подходит для локального полиномиального сглаживания; LSQ spline resampling — для гладкой кривой на заданной временной сетке. По возможности задавайте отдельную выходную колонку, сохраняя исходную для сравнения. Для SG и оконных методов проверяйте фактический интервал времени, покрытый окном точек; для сплайна — расстояние между узлами и диапазон новой временной сетки.
6. В **Column Manager** проверьте значения samples, единицы, активные привязки, provenance преобразований и сравнение качества. Убедитесь, что новая колонка содержит числа, а сглаживание не уничтожило тренд и не исказило результат.
7. Сохраните подготовленный опыт в типизированный CSV. Он сохраняет метаданные колонок и привязки, в отличие от сырого текстового экспорта. При необходимости откройте файл повторно и проверьте round-trip.

#### Отличия изотермического и неизотермического опыта

- **Изотермический опыт:** если температурной кривой нет, сохраните известную температуру в метаданных. Если датчик записывал температуру, привяжите колонку и при необходимости примените **Average on column** ко всему диапазону, чтобы посмотреть среднее значение. Используйте изотермические кинетические методы; скорость нагрева для такого опыта не задаётся.
- **Неизотермический опыт:** привяжите измеренную температурную кривую и укажите скорость нагрева в K/min. Если температура записана в градусах Цельсия, переведите её в Кельвины перед кинетическими расчётами. Проверьте `T vs t` и единицы: методу нужна корректная температурная история, а не только температура из метаданных.

### Серия экспериментов

1. Импортируйте каждый запуск как отдельный эксперимент с уникальным ID, описывающим условие, например `iso_500K` или `ramp_2Kmin`. Для каждого файла привяжите колонки и укажите изотермическую температуру либо скорость нагрева. Не объединяйте разные запуски в один эксперимент только ради создания серии.
2. Обрабатывайте запуски по очереди: удалите некорректное начало и окончание, при необходимости сдвиньте время, откалибруйте напряжение в массу, рассчитайте относительную массу/конверсию, затем примените выбранное сглаживание или ресемплирование. Для сравниваемых запусков сохраняйте одинаковый смысл колонок и согласованные единицы.
3. В **Column Manager** проверьте привязки, образцы данных и provenance каждого опыта. Режим compare-samples позволяет сопоставить выбранные колонки разных запусков; для графика не требуется принудительно выравнивать длину адаптивных или ресемплированных сеток.
4. После обработки сохраните типизированную серию. Перед запуском серийного кинетического метода проверьте входы каждого опыта: метаданные температуры для изотермического метода либо привязанная температурная колонка и скорость нагрева для неизотермического.

#### Изотермическая и неизотермическая серия

- **Изотермическая серия:** создайте отдельный эксперимент для каждой температуры; достаточно температуры в метаданных, колонка `T` необязательна. Независимо выполните калибровку массы, расчёт конверсии и сглаживание для каждого запуска. Проверьте ID и температуры, затем выберите изотермический серийный метод.
- **Неизотермическая серия:** создайте отдельный эксперимент для каждой скорости нагрева, привяжите температурную кривую и сохраните скорость в K/min. Выполните одинаковую последовательность предобработки для каждого опыта, проверяя допустимый диапазон конверсии и единицы температуры. Затем запустите неизотермический серийный метод.
- Не смешивайте режимы. Отсутствие `T` допустимо для явно изотермического опыта с известной температурой, но не заменяет температурную программу неизотермического опыта.
